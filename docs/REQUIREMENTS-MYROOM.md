## 4. 玩法规格（对齐原作）

### 4.1 触摸沟通（混合）

- 抚触驱动 **表情阶段**（F：适时停手更开心；过度→困扰）。  
- 同时填充 **Heart Gauge**（F2）：越满本段好感越多；**爆心则本段不加分**。  
- **反复爆心** → 生气（背对）；需礼物和/或成功填心和好。  
- **Fever**：连续成功后可戳击加速好感。  
- **会话上限 + 冷却**（UI：绿手势 → 达上限变淡）。  
- 背触：虚拟「背」按钮或双指空白模拟（无实体背屏）。

### 4.2 好感

- 等级 + 段内 gauge；`user://` 持久化。  
- 开局仅 **Miku** 房间逻辑槽；其它槽位按 Q11 解锁。

### 4.3 迷你游戏

1. **あっちむいてホイ**（猜拳 + 看方向）  
2. **アルプス一万尺**（点圆 / 滑箭头，多回合加速）  

触发：沟通成功或久留邀请（对齐 F2）；拒绝不降好感。

### 4.4 礼物 / 布置 / お願い（首期范围，按 Q10 顺序做）

- **礼物**：目录送礼；偏好表可简化。  
- **布置**：主题 / 简易家具切换。  
- **お願い**：气泡请求（换装路径/主题/BGM 等）；结果可由系统随机，玩家同意即可。

### 4.5 AR（后于 Room）

- **Portrait**：摄像头背景合影、缩放。  
- **Live**：平面放置模型 + 待机/短演出（非音游判定）。  
- 无实体 AR 卡（对齐 F2 Vita）。

## 6. 解锁（Q11=B）

- 计数：**任意 `official` 曲** 以 **NORMAL**（或以上，待实现时定）通关次数。  
- 阈值 `N` 与「第 2、3… 角色」阈值在实现计划里用配置表给出（可调）。  
- 解锁的是 **房间/角色槽**；模型仍来自占位或用户导入路径映射。
