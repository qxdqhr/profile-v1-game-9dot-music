# 9-Dot Game — 产品需求文档（PRD）

> **显示名**：9-Dot Game  
> **工程目录**：`app_games/9dot-music/`（旁路 `/games/9dot-music/`）  
> **状态**：**v1.0（grill 已收敛，可开工）**  
> **引擎**：Godot 4.x · 竖屏 Web 优先  
> **对标（重点）**：MikuFlick；参考 OSU / Phigros / Deemo / 邦多利

---

## 1. 一句话

竖屏九宫格音游：**节点亮起 → 点击（Tap）**；**两格之间的邻接边（含对角线）亮起 → 在该边上滑动（Slide）**。九宫格背后同步播放内置视频；**音频主时钟驱动判定与进度，严禁乱轴**。

## 2. 痛点与动机

在 B 站听/看音乐节目时，常在「九宫格锁屏」式键盘上随节奏点按、滑动。本品将该体感做成可判定、可选难度、可跟视频的正式音游（非轨道下落）。

## 3. 目标用户与场景

| 项 | 描述 |
|----|------|
| 用户 | 习惯跟节奏点划的听众；熟悉 MikuFlick / Deemo 等轻量音游的玩家 |
| 主场景 | 手机竖屏 Web；短局跟视频打谱 |
| 非目标（MVP） | 联机、UGC 上架、B 站链接在线生谱 |

## 4. 产品范围

### 4.1 MVP

- 主界面：标题 **9-Dot Game** · 进入游戏 · 设置 · 关于
- 选歌 → 难度（Easy / Normal / Hard / Extreme，缺档**灰显**）→ 游玩 → 结算
- 玩法：**仅两种 note — `tap`、`slide`**
- 谱面 JSON，时间单位 **`tMs`（毫秒整数）**
- 预制：内置 **audio + video**；音频 master，视频跟随
- 内容：先 **metronome + 简单循环/纯色视频** 跑通；正式曲后替换
- 难度：schema 预留四档；**先做 Normal 一条** 跑通全流程

### 4.2 后期（非 MVP）

- B 站链接 → Agent 生谱 + 视频缓存
- 百万制完整计分、谱面编辑器、账号云存、评级字母等


### 5.1 结算页（MVP）

- Accuracy%
- Max Combo
- Perfect / Great / Good / Miss 计数
- 操作：重试、回选歌
- **不做** S/A/B 等评级字母（后期可选）

## 6. 核心玩法

### 6.1 节点

```
  1  2  3
  4  5  6
  7  8  9
```

### 6.2 合法边

仅邻接（横 / 竖 / 对角，国王一步）。禁止长跨边（如 1–8）。

### 6.3 Note 类型（仅两种）

| `type` | 操作 | 判定要点 |
|--------|------|----------|
| `tap` | 点击对应节点 | 触点落在节点判定区；时刻对窗 |
| `slide` | 在**谱面指定的那条边**上，从一端附近滑向另一端 | 见下 |

不存在独立的 `flick` note。

**Slide 完成条件**：

1. 起点靠近边的一端（`dir` 所定义的起点）
2. 滑动过程保持在该边的**判定带**内（勿滑到其它边）
3. 滑动进度到达另一端附近（完成度 ≥ 约 **70%** 边长）
4. 整体落在判定时间窗内；方向错误或完全离边 → 低档或 Miss

**Slide 判定带宽度**：约 **35% 格宽**（实现常量，真机可调）。

**接近提示**：note 在 `tMs` 前 **500ms** 开始高亮/提示。

### 6.4 判定窗（音频时钟，相对 note `tMs`）

| 档位 | 窗口 |
|------|------|
| Perfect | ±50ms |
| Great | ±100ms |
| Good | ±150ms |
| Miss | 窗外，或未完成 Slide / 点错格 / 滑错边 |

**Miss 一律断连击。**

### 6.5 得分

- **百万制**：总分上限 1,000,000，按 note 数均分；Perfect=100% / Great=75% / Good=50% / Miss=0
- 同时保留连击与结算 **Accuracy%**

### 6.6 输入与时钟

- 多指：**至少双触点**
- **音频 master**；视频跟随；玩家偏移 + 谱面 `offsetMs`
- 禁止 UI 帧当音乐时间；暂停则音画与谱面同停

## 7. 谱面 JSON

```json
{
  "schemaVersion": 1,
  "id": "song-metronome-001",
  "title": "Metronome Lab",
  "artist": "",
  "bpm": 120,
  "offsetMs": 0,
  "audio": { "path": "res://charts/song-metronome-001/audio.ogg" },
  "video": {
    "source": "builtin",
    "path": "res://charts/song-metronome-001/video.webm",
    "cacheKey": "song-metronome-001"
  },
  "difficulties": {
    "easy": null,
    "normal": { "file": "normal.json" },
    "hard": null,
    "extreme": null
  }
}
```

```json
{
  "difficulty": "normal",
  "notes": [
    { "tMs": 2000, "type": "tap", "node": 5 },
    { "tMs": 3000, "type": "slide", "edge": [1, 5], "dir": "a_to_b" }
  ]
}
```

| 字段 | 约定 |
|------|------|
| `tMs` | 毫秒整数 |
| `edge` | `[a,b]` 合法邻接边；无单独 `edgeId` |
| `dir` | `a_to_b` \| `b_to_a` |
| 缺难度 | `null` → UI 灰显 |

## 8. 视频 / 音频（MVP）

| 项 | 约定 |
|----|------|
| 内置 audio + video | 要 |
| 首发内容 | **占位 metronome + 简单视频**，后换正式曲 |
| 边下边播 / B 站在线 | 禁止 / 非 MVP |
| 本地缓存远端 | 仅预留 |

## 9. 设置（MVP）

仅：主音量、判定偏移（ms）、恢复默认偏移。

## 10. 对标与差异

- **MikuFlick**：触控反馈、竖屏节奏感、结算呈现（计分深度后期对齐）
- 差异化：九宫格 + **边上 Slide** + 背后视频
