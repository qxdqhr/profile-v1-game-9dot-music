# 9-Dot Game — 产品需求文档（PRD）

> **显示名**：9-Dot Game  
> **工程目录**：`app_games/9dot-music/`（旁路 `/games/9dot-music/`）  
> **状态**：**v1.2（表现与 Slide Arm grill 已收敛）**  
> **引擎**：Godot 4.x · 竖屏 Web 优先 · APK 真机反馈完整  
> **对标（重点）**：MikuFlick；**表现参考 Project DIVA（歌姬计划）箭头 / 接近可读性**；参考 OSU / Phigros / Deemo

---

## 1. 一句话

竖屏九宫格音游：**节点亮起 → 点击（Tap）**；**两格之间的邻接边（含对角线）亮起 → 在该边上滑动（Slide）**。九宫格背后同步播放内置视频；**音频主时钟驱动判定与进度，严禁乱轴**。

## 2. 痛点与动机

在 B 站听/看音乐节目时，常在「九宫格锁屏」式键盘上随节奏点按、滑动。本品将该体感做成可判定、可选难度、可跟视频的正式音游（非轨道下落）。

## 3. 目标用户与场景

| 项 | 描述 |
|----|------|
| 用户 | 习惯跟节奏点划的听众；熟悉 MikuFlick / Deemo 等轻量音游的玩家 |
| 主场景 | 手机竖屏 Web；短局跟视频打谱 |
| 非目标（MVP） | 联机、UGC 上架、B 站链接在线生谱 |

## 4. 产品范围

### 4.1 MVP

- 主界面：标题 **9-Dot Game** · 进入游戏 · 设置 · 关于
- 选歌 → 难度（Easy / Normal / Hard / Extreme，缺档**灰显**）→ 游玩 → 结算
- 玩法：**仅两种 note — `tap`、`slide`**
- 谱面 JSON，时间单位 **`tMs`（毫秒整数）**
- 预制：内置 **audio + video**；音频 master，视频跟随
- 内容：先 **metronome + 简单循环/纯色视频** 跑通；正式曲后替换
- 难度：schema 预留四档；**先做 Normal 一条** 跑通全流程

### 4.2 后期（非 MVP）

- B 站链接 → **离线** Agent 生谱 + 视频缓存（见 `docs/skills/nine-dot-chart-agent/`，非游戏内菜单）
- 百万制完整计分、谱面编辑器、账号云存、评级字母等

## 5. 信息架构

```
启动闪屏（标题 · 点击任意处继续）
└── 主页 Hub
    ├── 节奏游戏 → 选歌（官方/我的）→ 难度 → 游玩 → 结算
    │                              └── 重试 / 回选歌 / 回主页
    ├── MyRoom（占位，后期个人空间）
    ├── 设置（Tab：游戏 / 视频 / 音量）
    └── 关于
```

- 闪屏：品牌标题为英雄级信号；任意点击 / 确认键进入 Hub
- Hub：主 CTA「节奏游戏」；MyRoom / 设置 / 关于
- 曲库：运行时 `user://songs`（首次从 `res://charts` seed）；键 `category/id`
- 游玩：视频在九宫格背后；曲名标题框；判定柱（Judge→Combo→Score→Acc）；底进度条；暂停
- 缺难度文件：四档可见，**灰显不可点**
- 设置入口：Hub / 选歌状态栏；返回记忆 `PlaySession.settings_back_scene`

### 5.1 结算页（MVP）

- Accuracy%
- Max Combo

- 操作：重试、回选歌
- **不做** S/A/B 等评级字母（后期可选）

## 6. 核心玩法

### 6.1 节点

```
  1  2  3
  4  5  6
  7  8  9
```

### 6.2 合法边

仅邻接（横 / 竖 / 对角，国王一步）。禁止长跨边（如 1–8）。

### 6.3 Note 类型（仅两种）

| `type` | 操作 | 判定要点 |
|--------|------|----------|
| `tap` | 点击对应节点 | 触点落在节点判定区；时刻对窗 |
| `slide` | 在**谱面指定的那条边**上，从一端附近滑向另一端 | 见下 |

不存在独立的 `flick` note。

**Slide 完成条件（v1.2）**：

1. **Arm（接住）**：在 `[tMs - APPROACH_MS, tMs + JUDGE_GOOD_MS]` 内于起点附近按下，锁定该边（见 §6.7）
2. **Tracking**：滑动过程保持在该边的**判定带**内；允许 **80ms** 离带 grace，超时未回则失败
3. 滑动进度到达另一端附近（完成度 ≥ **55%** 边长）
4. **结算时刻**落在 Slide 专用时间窗内（§6.4）；方向错误或离带超时 → Miss

**Slide 判定带宽度**：约 **35% 格宽**（实现常量，真机可调）。

**接近提示**：note 在 `tMs` 前 **`APPROACH_MS = 700ms`** 开始接近动画 / 箭头（见 §6.8）。

### 6.4 判定窗（音频时钟，相对 note `tMs`）

**Tap**（与填满视觉硬绑定：内圆在 `tMs` 刚好填满外环）：

| 档位 | 窗口 |
|------|------|
| Perfect | ±50ms |
| Great | ±100ms |
| Good | ±150ms |
| Miss | 窗外，或点错格 |

**Slide**（专用更宽窗；完成时刻 = 首次进度 ≥ 55% 的时刻，或抬起且已达标时）：

| 档位 | 窗口 |
|------|------|
| Perfect | ±80ms |
| Great | ±140ms |
| Good | ±220ms |
| Miss | 窗外，或未完成 / 滑错边 / 离带超时 |

**Miss 一律断连击。**

命中 HUD：**档位字 + Early/Late**（Miss 除外）。偏差 ms 仅开发调试开关，正式局默认关。

### 6.5 得分

- **百万制**：总分上限 1,000,000，按 note 数均分；Perfect=100% / Great=75% / Good=50% / Miss=0
- 同时保留连击与结算 **Accuracy%**

### 6.6 输入与时钟

- 多指：**至少双触点**
- **音频 master**；视频跟随；玩家偏移 + 谱面 `offsetMs`
- 禁止 UI 帧当音乐时间；暂停则音画与谱面同停

### 6.7 Slide 生命周期（v1.2 · Arm / Track / Judge）

对标歌姬计划「方向一眼可读 + 动作可接住」，逻辑模型：

| 阶段 | 条件 | 行为 |
|------|------|------|
| **Arm** | `now ∈ [tMs - 700, tMs + 150]` 且触点近起点 | 锁定该 slide；播接住短振（若开振动） |
| **Tracking** | 触点在边带内（含 80ms grace） | 更新进度；行进箭头跟随 |
| **Judge** | 进度 ≥ 0.55 | 用 Slide 窗对完成时刻打分；完成强振；消费 note |
| **Fail** | 离带超时 / 方向错 / 超时未完成 | Miss |

本轮 **改表现 + Arm/Track**；Clock 三项式与校准页见 `docs/RESEARCH-RHYTHM-FEEL.md`，不在本版本强制范围。

### 6.8 视觉与反馈规范（v1.2 · 对标歌姬可读性）

#### Tap — 环带内缩填充

- 外环固定；**内圆半径随接近进度增大**，在 `tMs` **刚好填满**外环（硬绑定 §6.4）。
- 主色：**品红 / 玫红半透明填充 + 高对比描边**（与 Slide 暖黄区分）。
- 禁止仅「边缘圆周闪一下」作为唯一接近提示。
- 命中：爆闪 / 短粒子 + 档位字 + Early/Late + Tap 击打音。

#### Slide — 行进箭头列

- 沿指定边从起点到终点排列**多个小箭头**，向终点流动（歌姬 Slide 方向感）。
- 主色：**暖黄**；未接住时脉冲，Tracking 中箭头加速/高亮已走过段。
- 命中/完成：完成特效 + 档位字 + Early/Late + Slide 击打音。

#### 触感（APK 优先）

| 事件 | 反馈 |
|------|------|
| Slide 接住（Arm 成功） | 短振 ≈ **25ms** |
| Slide 完成（Judge 成功） | 较强振 ≈ **40ms** |
| Miss（可选） | 不振或极弱双短振（实现可省略） |

- 设置：**总开关「振动」**（默认开）。无独立轻/强档。
- 实现：`Input.vibrate_handheld`；Android 导出须启用 **`VIBRATE`** 权限。
- Web：有 Vibration API 则跟随开关，否则静默跳过。

#### 击打音

- Tap / Slide **分音色**；默认开。
- 设置增加 **「击打音」开关**（跟随主音量，无独立音量滑条）。延迟敏感玩家可关。

#### Schema

- **本轮不改谱面 JSON**；`approachMs` / 每曲 slide 窗等覆盖留后期。

## 7. 谱面 JSON

```json
{
  "schemaVersion": 1,
  "id": "song-metronome-001",
  "title": "Metronome Lab",
  "artist": "",
  "bpm": 120,
  "offsetMs": 0,
  "audio": { "path": "res://charts/song-metronome-001/audio.ogg" },
  "video": {
    "source": "builtin",
    "path": "res://charts/song-metronome-001/video.webm",
    "cacheKey": "song-metronome-001"
  },
  "difficulties": {
    "easy": null,
    "normal": { "file": "normal.json" },
    "hard": null,
    "extreme": null
  }
}
```

```json
{
  "difficulty": "normal",
  "notes": [
    { "tMs": 2000, "type": "tap", "node": 5 },
    { "tMs": 3000, "type": "slide", "edge": [1, 5], "dir": "a_to_b" }
  ]
}
```

| 字段 | 约定 |
|------|------|
| `tMs` | 毫秒整数 |
| `edge` | `[a,b]` 合法邻接边；无单独 `edgeId` |
| `dir` | `a_to_b` \| `b_to_a` |
| 缺难度 | `null` → UI 灰显 |

## 10. 对标与差异

- **MikuFlick**：触控反馈、竖屏节奏感、结算呈现（计分深度后期对齐）
- **Project DIVA（歌姬计划）**：Slide **方向箭头可读性**、接近提示必须「还剩多久一目了然」；本品 Tap 用**填满圆**而非飞入重合（更贴九宫格定点）
- 差异化：九宫格 + **边上 Slide** + 背后视频

## 11. 非功能

- `/games/9dot-music/`；`sa2kit_godot` CJK
- 中低端机：视频 + 判定不掉节奏
